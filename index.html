How this demo works

This demo uses my own Intelligent Decision-Support System idea as the example. Edit the idea, add evidence, generate a transparent illustrative review, and mark experiments complete. All information stays in this browser.

This is a clickable workflow prototype, not a connected AI engine. Suggested insights are example decision-support logic, not independently verified findings.
